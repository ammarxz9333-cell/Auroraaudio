# Aurora software validation

This directory contains end-to-end software gates that are intentionally independent of a named physical device.

- `immersive/`: real E-AC-3 JOC / IEC61937 / Harletty / Omniphony validation.
- `surround-upmix/`: channel-based E-AC-3/AC-3 decode plus explicitly synthetic height ambience.

These tests prove software behavior only. They do not imply certification, DRM access, eARC hardware support, DAC/amplifier quality, or physical latency.

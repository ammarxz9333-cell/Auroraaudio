# Aurora Post-Core Product Features

These items are mandatory for the final appliance, but implementation must follow the active execution roadmap and may not skip renderer/network/hardware acceptance gates.

1. Safe update / snapshot / automatic rollback system.
2. Plugin Manager with permissioned out-of-process extensions and rollback.
3. Home Assistant / MQTT integration as an optional plugin.
4. Unified diagnostics, fault injection, self-healing and sanitized support bundle.
5. Product-level Capability Registry integration using existing issue #45.

Primary specifications:
- `docs/AURORA_PRODUCT_FOUNDATIONS_CONTRACT.md`
- `docs/acceptance/AURORA_PRODUCT_FOUNDATIONS_ACCEPTANCE.md`

These requirements must be included in final release planning and validation.

# Aurora targeted worldwide gap-solvers audit — 2026-10-11

Status: **research only**, no new dependency added to the lean runtime. The search is broad and time-bounded, not an impossible claim to have enumerated every global repository. This document de-duplicates against the existing 29-project external-component research inventory and existing Aurora codec, wireless and eARC projects.

## Core blocker remains an actual universal HDMI/eARC receiver

Audio codec decoding and HDMI/eARC receiving are different engineering stages. No newly reviewed repository provides proven, fully open, end-to-end Dolby MAT 2.0 + TrueHD HBR + DD+ JOC + DTS:X + AC-4 transport acquisition on the selected Aurora physical hardware, nor real Netflix/Disney+/Prime Video 7.1.4 playback. HDMI TX-only FPGA cores and commercial HDMI passthrough extractors are NOT computer-ready raw encoded PCM ingest adapters. The legacy Lindy/SiI9437 E-AC-3 capture is narrowly verified; do not call it universal MAT/HBR.

## Permanent integration rule

Keep only the strongest demonstrated *replacement* per role. **No new runtime library has been added by this audit.** Before accepting a candidate: verify exact source commit/release, build reproducibility, measured 12ch native route, same-host decode and P95/P99 timing, synchronization/latency, memory usage, actual supported codec metadata, error recovery, license requirements, and physical selected hardware behavior. Existing `docs/lean-audio-stack.md` remains authoritative; only replace a current owner if a candidate outperforms it under the same corpus and hardware. No simultaneous duplicate decoders/renderer or always-on fallback.

## Minimum next lab experiments

1. **12ch USB output gate:** use XMOS v9.2.0 exact tagged source with a board exposing the necessary USB audio descriptors; distinguish its default 8 analogue outputs from any ADAT expansion. Measure 12 independent final DAC output channels, clipping, jitter, ALSA access and XRUNs.
2. **TrueHD Atmos gate:** obtain authorized non-DRM conformance stream; compare truehdd's PCM+OAMD object metadata with Harletty+Omniphony, including 7.1.2 heights and timing. Fail if object count/position/PCM map disagrees.
3. **Wireless gate:** preserve existing Aurora single protocol until an identical-12ch bench on at least 3 wireless endpoints measures actual playout latency, P99 skew, drift correction, loss concealment and rejoin. Music multiroom demonstrations cannot meet this gate.
4. **eARC universal gate:** no new receiver accepted without real MAT, HBR TrueHD/DTS-HD, DD+ JOC and PCM format negotiation + raw arrival evidence from legitimate TV/streamer. Don't advertise every format before this gate is physically demonstrated.

Do not claim an exhaustive census of world projects, real-life physical evidence, certified Dolby rendering or full 7.1.4 hardware success on the basis of README text alone.
